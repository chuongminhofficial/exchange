# Changelog / Lịch Sử Phiên Bản

## [v4.0.0] — 2026-10
### 🇬🇧 English
* **Bilingual In-Memory JSON Engine (`en` / `vi`)**: Added zero-latency switching between English (`en`, default) and Vietnamese (`vi`) across all 26+ public endpoints via `?lang=`, `X-Language`, or `Accept-Language`.
* **Commercial Host Firewall (`Allow Host` & `Disable Host`)**: Automatic URL/Link normalization to canonical hostnames/IPs and `X-Client-Host` support for Server-to-Server backend verification.
* **Official 4-Language SDK Suite**: Released v4.0 client SDKs for JavaScript/TypeScript (`.d.ts` included), PHP (Persistent cURL Keep-Alive), Python (Zero-Dependency), and Go (Full 28-method parity).
* **Bilingual Postman Collections**: Added English and Vietnamese Postman v2.1.0 collections covering all 5 endpoint groups.

### 🇻🇳 Tiếng Việt
* **Cơ Chế Phản Hồi JSON Song Ngữ Tự Động (`en` / `vi`)**: Chuyển đổi tức thì độ trễ 0ms giữa Tiếng Anh (`en`, mặc định) và Tiếng Việt (`vi`) trên toàn bộ 26+ Public Endpoints.
* **Tường Lửa Tên Miền Chuẩn Thương Mại (`Allow Host` & `Disable Host`)**: Tự động chuẩn hóa mọi URL/Link về hostname/IP chuẩn và hỗ trợ header `X-Client-Host` cho kết nối từ máy chủ Backend.
* **Bộ SDK Chính Thức 4 Ngôn Ngữ**: Phát hành đồng bộ SDK v4.0 cho JavaScript/TypeScript (kèm `.d.ts`), PHP (Persistent cURL Keep-Alive), Python (không phụ thuộc gói ngoài) và Go (đầy đủ 28 hàm gọi).
* **Bộ Sưu Tập Postman Song Ngữ**: Cung cấp file Postman Collection v2.1.0 bằng cả Tiếng Anh và Tiếng Việt.
